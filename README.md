# WoW Auction Intelligence

Локальное приложение для WoW Retail. Этап 1 принят с отложенными реальными
проверками: чтение GX, BagSync, TSM Ledger и структуры CraftSim, согласование
имущества. Этап 2 добавляет отдельное рыночное хранилище и импорт публичных
CSV TSM без ключей. Игровые файлы открываются только для чтения.

**Blizzard API не используется и не требуется.** Регистрация Battle.net API,
Client ID/Secret, телефон и Authenticator для приложения не нужны.
Адаптер Undermine подготовлен; реальное получение его данных пока недоступно
из-за отсутствия собственного ключа UE и открытого вопроса условий хранения.

В R2 этапа 2 закрыты все четыре программных замечания. Пользователь принял
подтверждённую часть, перенёс недоступные реальные проверки и разрешил этап 3
([решение D2](docs/stage-3-transition.md)). Этап 3 добавляет отдельный каталог
преобразований и читающий мост CraftSim. Источник, версия, пробелы и граница
доказательств сохраняются; импортированный кандидат ещё не торговая рекомендация.
