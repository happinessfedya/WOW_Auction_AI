## Метаданные предметов: выполненная часть этапа 3

Добавлен самостоятельный bounded decoder [knowledge_items.py](../../wow_auction/knowledge_items.py) для **локального** `TSMItemInfoDB` версии `19`. Он не исполняет Lua, не копирует код аддона и не публикует его кэш. Возвращает exact `source_item_string`, локализованное имя, build/locale и 13 сохранённых полей. Известное представление фиксируется версией; неизвестная версия, длина, алфавит, разрывы chunks, дубликаты ключей или некорректные флаги отклоняются целиком. Нулевые значения отличаются от nil; mismatch build означает `stale_build`, а совпадение build не объявляет известным возраст каждой записи.

| Поле | Сохраняемая семантика |
|---|---|
| itemLevel, minLevel | Уровень предмета и минимальный уровень из кэша |
| vendorSell | Сохранённая цена продажи NPC в меди; не текущая рыночная цена |
| maxStack, invSlotId, texture | Максимальная пачка, source slot enum, texture ID |
| classId, subClassId, quality | Source class/subclass/rarity enums |
| isBOP | Шаблонный флаг, в прочитанном wrapper объединяет bind-on-acquire и quest binding; не состояние конкретной вещи |
| isCraftingReagent, expansionId | Source flag и source expansion enum; enum не подменяется названием дополнения |
| craftedQuality | Source enum без преобразования в tier: установленный код также использует значения `quality + 10` |

Реальный кэш `19,ruRU,12.1.5,70575`: **18 066 item keys + 920 pet keys = 18 986**, 132 ключа с дополнительными полями. У 268 записей isBOP unknown, у 18 718 — 0; значение1 не встретилось. Из 254 inventory rows 222 имеют только base-ID match с isBOP0, 32 не имеют его. **Ни одна строка имущества не была повышена до подтверждённой торгуемости.** Нулевой флаг не доказывает отсутствие другого binding, а source key TSM не доказывает эквивалентность BagSync lossly identity.

Первичные локальные источники контракта прочитаны в установленном TradeSkillMaster: `ItemInfoSerializer.lua:20–35,94–134`; `ItemInfoCache.lua:18–25,126–140`; `LongString.lua:22–48`; `LibTSMWoW/Source/API/Item.lua:31–34`; `LibTSMService/Source/Item/ItemInfo.lua:994–1046`; `ItemInfoConfig.lua`. Полные SHA этих шести файлов находятся в JSON. Собственные семантические допущения не подменяют runtime comparison. Лицензия TSM ARR не превращена в разрешение массовой перепубликации: decoder работает с локальными личными SavedVariables, cache rows остаются приватными; дальнейшие права использования отделены от возможности прочитать формат.

Семь [тестов](../../tests/test_knowledge_items.py) проверяют независимые literal fixtures для разрядности/порядка цифр и nil, zero versus unknown, вариативные ключи, stale build, chunk/row count/identity/flag/alphabet/schema failures и безопасные diagnostics. Результат: **7/7 PASS**. Реальный локальный decode дополнительно выполнен в probe; это не сверка всех значений с интерфейсом WoW.
