После уточнения пользователя ручное открытие рецепта/scan исключены из обязательного процесса: добавлены автоматическое чтение кэшей и пассивный сбор при обычной сессии; fresh API runtime остаётся непроверенным до естественного нового сохранения. [Текущий протокол CraftSim](research/stage-3-craftsim.md), [новые доказательства прежних проверок](research/stage-3-prior-verifications.md). **Нормативное решение 26.10.2026:** пользователь запретил получение и использование любых Blizzard client ID/secret и прямого Blizzard API. Q02 закрыт отказом от этого пути и больше не является запросом доступа. Запуск TSM работает без ключей; альтернативы и текущие ограничения — [матрица без Blizzard](research/stage-2-no-blizzard-alternatives.md). Отказ от Blizzard не означает согласия на UE-регистрацию, платную подписку или scraping сайта.

Q02 больше не открытая зависимость. Q03/Q06 относятся только к выбранному UE/иному допустимому источнику и правам; их отсутствие не запрещает независимый TSM-импорт и не разрешает скрытый fallback. Ключи не ищутся в системе и не публикуются; для CraftSim ключ не требуется. Первоначальное отсутствие сделок и прежний опыт сохранены исторически; актуальные дальнейшие покупки/ремонт/Vendor sale уже учтены аудитором. Новые доступные события проверяются при следующей приёмке, а не отбрасываются по старому отчёту; полная история и оставшиеся S1-V01–V07 этим не объявляются доказанными.

Рутинные архитектурные варианты (FastAPI/HTML, SQLite/worker, DTO) уже описаны с обоснованием. Они не требуют немедленно выбирать каждую библиотеку; проверяющий может оспорить их на основании требований. Принципиальные права, денежные пределы и переход этапа за пользователя не решаются.
